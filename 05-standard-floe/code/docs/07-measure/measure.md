## 숫자 재기

> 2단계에서 정한 숫자를 실제로 재 보기

- 지역 추천: 날짜 넣고 지역 이름 나오나 / 맛집 찾기: 지역 넣고 목록 나오나 / 리포트: 한 장 나오나
- 어떻게: 고름 — 플로로가 권한 것: “지역 추천: 날짜 넣고 지역 이름 나오나 / 맛집 찾기: 지역 넣고 목록 나오나 / 리포트: 한 장 나오나”
- 재료: 3단계 Ⅱ 숫자로 · 6단계 Ⅰ 확인 먼저 · 6단계 Ⅲ 써 보기
