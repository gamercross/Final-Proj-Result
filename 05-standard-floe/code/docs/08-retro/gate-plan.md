## 2. 이번 단계에서 한 일

- 잘된 점과 아쉬운 점 돌아보기 — 잘된 점: 시험 27개가 통과했어요 · 아쉬운 점: 실제 열쇠로는 아직 안 돌려 봤어요.
- '왜?'를 다섯 번 물어 진짜 원인 찾기 — 왜? 실제로 안 돌려 봤나 → 열쇠가 없었나 → 먼저 가짜로 시험했나 → 진짜 확인을 뒤로 미뤘나 → 확인할 날을 안 정했어요.
- 정보가 샐 뻔했던 일이나 아찔했던 일 적기 — 없었어요 — 다음엔 여행 날짜 말고 다른 정보가 AI나 지도에 가지 않는지 먼저 시험할게요.
- 배운 것을 다음에 쓸 수 있게 남기기 — 다음엔 성공 숫자를 먼저 정해요 / 다음엔 실제 열쇠로 한 번 돌려 봐요 / 다음엔 열쇠를 올리기 전에 검사해요.
- 마친 작업을 저장소에 올려 두기 — travel_planner.py와 시험 파일, 문서 — 커밋: 여행 리포트 첫 판 완성 (열쇠와 .env는 올리지 않아요)
