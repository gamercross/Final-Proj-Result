## 후보 찾기

> 흔히 쓰는 방법 목록에서 먼저 후보를 2개 이상 찾기

- 서버가 있는 웹 / 화면 하나짜리 웹 / 휴대폰 앱
- 어떻게: 고름 — 플로로가 권한 것: “서버가 있는 웹 / 화면 하나짜리 웹 / 휴대폰 앱”
- 재료: 1단계 Ⅳ 크기 · 3단계 Ⅰ 기능 문장

## 견주기

> 후보끼리 좋은 점과 아쉬운 점 비교하기

- 서버 웹: 열쇠 숨김 · 손이 많이 가요 / 한 화면 웹: 쉬움 · 열쇠 노출 / 휴대폰 앱: 편함 · 준비 길어요
- 어떻게: 고름 — 플로로가 권한 것: “서버 웹: 열쇠 숨김 · 손이 많이 가요 / 한 화면 웹: 쉬움 · 열쇠 노출 / 휴대폰 앱: 편함 · 준비 길어요”
- 재료: 2단계 Ⅱ 왜 · 어디까지 · 언제 성공 · 3단계 Ⅲ 꼭 · 있으면 좋음

## 고른 까닭

> 고른 방법과 왜 골랐는지 한 줄을 기록으로 남기기

- 고른 방법: 서버가 있는 웹 — 까닭: AI와 지도를 차례로 부르고, 다른 정보가 나가는 걸 서버에서 막을 수 있어요
- 어떻게: 고름 — 플로로가 권한 것: “고른 방법: 서버가 있는 웹 — 까닭: AI와 지도를 차례로 부르고, 다른 정보가 나가는 걸 서버에서 막을 수 있어요”
- 재료: 1단계 Ⅳ 크기 · 3단계 Ⅰ 기능 문장 · 3단계 Ⅴ 막을 일

## 약속과 맞대기

> 지키기로 한 원칙(쓸 도구, 하면 안 되는 것, 화면 원칙)과 고른 방법 맞대어 보기

- Python 쓰기: 맞음 — 서버에서 쓸 수 있어요 / 다른 정보 안 보내기: 맞음 — 서버에서 걸러요 / 화면 원칙: 아직 모름
- 어떻게: 고름 — 플로로가 권한 것: “Python 쓰기: 맞음 — 서버에서 쓸 수 있어요 / 다른 정보 안 보내기: 맞음 — 서버에서 걸러요 / 화면 원칙: 아직 모름”
- 재료: 2단계 Ⅳ 남의 정보 · 밖으로 · 3단계 Ⅴ 막을 일
