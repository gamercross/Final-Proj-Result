## 끝까지 잇기

> 가장 단순한 흐름을 처음부터 끝까지 이어 보기

- ① 여행 날짜 넣기 → ② AI가 좋은 지역 추천 → ③ 지도로 맛집 찾기 → ④ 여행 리포트 보여 주기
- 어떻게: 고름 — 플로로가 권한 것: “① 여행 날짜 넣기 → ② AI가 좋은 지역 추천 → ③ 지도로 맛집 찾기 → ④ 여행 리포트 보여 주기”

## 도는지 보기

- 어떻게: 고름 — 플로로가 권한 것: “날짜를 넣어 보면 → 추천 지역과 맛집이 담긴 리포트가 화면에 나오면 된다”
