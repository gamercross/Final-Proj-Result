## 확인 먼저

> 확인 방법을 먼저 정하고 만들기

- 지역 추천 — 날짜를 넣으면 지역 이름이 나와야 해요 / 맛집 찾기 — 지역을 넣으면 맛집 목록이 나와야 해요 / 리포트 — 결과를 넣으면 한 장이 나와야 해요
- 어떻게: 고름 — 플로로가 권한 것: “지역 추천 — 날짜를 넣으면 지역 이름이 나와야 해요 / 맛집 찾기 — 지역을 넣으면 맛집 목록이 나와야 해요 / 리포트 — 결과를 넣으면 한 장이 나와야 해요”
- 재료: 3단계 Ⅰ 기능 문장 · 5단계 Ⅱ 도는지 보기 · 5단계 Ⅲ 작게 나누기
