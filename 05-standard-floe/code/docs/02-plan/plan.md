## 빈칸 채우기

> 정해진 빈칸에 아이디어 채우기

- 누구: 여행 날짜를 넣는 사용자 · 불편: 어디가 좋은지, 어디서 먹을지 하나하나 찾기 어려워요 · 해결: 날짜만 넣으면 추천 지역과 맛집 리포트 · 어디까지: 추천, 맛집…
- 어떻게: 플로로 초안을 그대로 — 플로로 초안: “누구: 여행 날짜를 넣는 사용자 · 불편: 어디가 좋은지, 어디서 먹을지 하나하나 찾기 어려워요 · 해결: 날짜만 넣으면 추천 지역과 맛집 리포트 · 어디까지: 추천, 맛집…”
- 재료: 1단계 Ⅰ 불편 · 1단계 Ⅱ 달라지는 것 · 1단계 Ⅲ 누가 · 1단계 Ⅳ 크기

## 왜 · 어디까지 · 언제 성공

> 왜 만드는지, 어디까지 만들지, 언제 성공인지 답하기

- 왜: 여행지와 맛집을 하나하나 찾기 힘들어서 · 어디까지: 지역 추천, 맛집 검색, 리포트(예약과 길찾기는 이번에 안 해요) · 언제 성공: 아직 모름
- 어떻게: 플로로 초안을 그대로 — 플로로 초안: “왜: 여행지와 맛집을 하나하나 찾기 힘들어서 · 어디까지: 지역 추천, 맛집 검색, 리포트(예약과 길찾기는 이번에 안 해요) · 언제 성공: 아직 모름”
- 재료: 1단계 Ⅰ 불편 · 1단계 Ⅱ 달라지는 것 · 1단계 Ⅳ 크기

## 한 문장 한 가지

> 한 문장에 한 가지 일만, 애매한 말 없이 쓰기

- 여행 날짜를 넣으면, 앱은 좋은 지역을 추천한다 / 지역이 정해지면, 앱은 그 지역의 맛집을 찾는다 / 결과가 모이면, 앱은 여행 리포트를 만든다
- 어떻게: 플로로 초안을 그대로 — 플로로 초안: “여행 날짜를 넣으면, 앱은 좋은 지역을 추천한다 / 지역이 정해지면, 앱은 그 지역의 맛집을 찾는다 / 결과가 모이면, 앱은 여행 리포트를 만든다”
- 재료: 1단계 Ⅱ 달라지는 것 · 1단계 Ⅲ 누가

## 남의 정보 · 밖으로

> 다룰 정보에 남의 정보가 섞이는지, 무엇이 밖으로 나가는지 적기
