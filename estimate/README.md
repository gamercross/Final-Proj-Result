# 토큰 예측 — 사람이 "앱"까지 갈 때

> **이 문서의 100만 · 52만은 잰 값이 아니라 예측 · 추정이다.** 잰 값은 [루트 README의 "성능" 표](../README.md#성능--토큰--시간--비용)에 있다. 2026-11-12 이재엽.

발표에서 "같은 앱을 만드는 데 Floe 없이는 약 100만 토큰, Floe와는 약 52만 토큰"이라고 말한다. 그 숫자가 어디서 나왔고 어디까지가 잰 것인지 적어 둔다.

## 한눈에

| | 토큰 | 종류 | 근거 |
|---|---:|---|---|
| AI 혼자 한 번에 만든 것(04 · 명령줄 프로그램) | 100,648 | **잰 값** | 새로 읽은 71,231 + 쓴 29,417 |
| Floe를 거쳐 한 번에 만든 것(05 · 명령줄 프로그램) | 309,890 | **잰 값** | 새로 읽은 180,897 + 쓴 44,561 + Floe 초안 84,432 |
| 사람 + Floe로 **앱까지**(첫 실행 test-1 → 웹 앱) | 약 52만 | **추정** | 잰 조각의 합 501,619에 못 잰 몫을 더한 어림(아래) |
| Floe 없이 사람 + AI로 **앱까지** | 약 100만 | **예측** | 해 본 적 없음 — 한 번 만드는 값(100,648)의 약 10배라는 가정(아래) |

**잰 값만 보면 Floe가 토큰을 더 쓴다**(04 약 10만 · 05 약 31만 — 약 3배). 한 번에 끝나는 일에서는 AI 혼자가 싸다. 아래 예측은 "한 번에 끝나지 않을 때", 곧 AI가 묻지 않고 정한 것이 사람이 원한 것과 달라 다시 만들어야 할 때의 이야기다.

## 사람 + Floe로 앱까지 — 약 52만(추정)

사람이 Floe 여덟 단계를 지나며 정한 것(35칸 · 관문 8번)으로 웹 앱이 나오기까지를, 남아 있는 기록으로 더했다.

| 조각 | 토큰 | 어디서 |
|---|---:|---|
| 첫 실행 중 Floe가 Claude Code에 넘긴 일 12세션(2026-10-24 ~ 11-04, Sonnet) | 269,398 | 그 폴더의 Claude Code 세션 기록을 2026-11-12에 더함 — 새로 읽은 259,048 + 쓴 10,350 |
| 그 문서로 웹 앱 코드를 만든 실행(03 `code/`) | 147,789 | [03 README](../03-test-1-run-1/README.md) — 새로 읽은 128,919 + 쓴 18,870 |
| Floe 초안 8번 | 84,432 | 첫 실행 때는 따로 남기지 않아 **05에서 잰 값을 빌렸다(가정)** |
| **합** | **501,619** | |

- 세는 법은 루트 README와 같다 — "새로 읽은"(캐시에 새로 쓴 입력) + "쓴"(출력). 같은 내용을 다시 읽은 몫은 세지 않았다.
- 못 잰 몫이 있다: 첫 실행의 초안 토큰(위에서 빌린 값), 사람이 고쳐 달라고 다시 맡긴 일. 그래서 50만을 아래쪽 끝으로 보고 **약 52만**으로 잡았다(발표 덱의 앞 판은 "54만+(예상)").
- 세션 기록 원본에는 대화 내용이 들어 있어 이 공개 저장소에 싣지 않았다. 합계만 적는다.

## Floe 없이 사람 + AI로 앱까지 — 약 100만(예측)

**이 실험은 하지 않았다.** 아래는 가정이다.

- 04에서 AI는 미션을 "리포트를 만드는 명령줄 프로그램"으로 이해했고, 정해야 할 네 가지(오류 종류 · 캐시 · 추천 지역 수 · 리포트 짜임)를 묻지 않고 혼자 정했다. 사람이 원한 것이 웹 앱이었다면 이 결과는 다시 만들어야 한다.
- 한 번 만드는 데 100,648토큰이 들었다. **다시 만들기가 약 10번 분량**(방향을 바꿔 다시 맡기기, 정하지 않은 값 때문에 되돌아가기, 길어진 대화를 다시 읽기)이라고 보면 약 100만이다.
- "10번"에는 근거가 되는 측정이 없다. 실제로는 훨씬 적을 수도, 많을 수도 있다.

## 읽는 법

- 발표에서 이 숫자를 말할 때는 **"예측" · "추정"** 이라고 말한다. "절반으로 줄었다"가 아니라 "절반 가까이 줄 것으로 예측한다"이다.
- 확인하려면: Floe 없이 사람이 Claude Code와 같은 미션을 웹 앱까지 만들며 토큰을 남긴다(한 번이라도). 그 값이 나오면 이 문서의 예측을 잰 값으로 바꾼다.
