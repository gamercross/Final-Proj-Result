Travel Planner 🌍

국내 여행 추천 프로그램 — 날짜를 넣으면 추천 지역(LLM) → 맛집 검색(지도 API) → 최종 리포트(LLM) 순서로 만듭니다.

실행

python travel_planner.py -date
